# 运营数据指标口径字典

日期：2026-07-08

## 全局口径

- 默认时间范围：最近 30 天。
- 时间过滤字段：用户按 `createdAt` 或 `lastActiveAt`；学习记录按 `completedAt`；审核任务按 `submittedAt`、`updatedAt`；反馈按 `createdAt`、`updatedAt`。
- 考试类型过滤：仅统计可识别 `examType` 的数据；无考试类型字段的数据只参与与考试无关的汇总。
- 趋势粒度：`day` 按自然日，`week` 按周桶，`month` 按自然月桶。
- 对比口径：当前区间与前一等长区间做简单环比。
- 空分母处理：比例类指标分母为 0 时展示 0，并写入数据质量提示。

## 核心指标卡

| 指标 | 口径 | 类型 |
| --- | --- | --- |
| 新增用户 | 当前时间范围内创建的用户数 | 正式 |
| 活跃用户 | 当前时间范围内有最近活跃记录的用户数 | 正式 |
| 今日任务完成率 | 完成今日任务用户数 / 有今日任务用户数 | 正式 |
| 待审核任务 | 当前筛选范围内待审核审核任务数 | 正式 |
| 题库可发布内容 | 已通过、待发布、已发布题目数 | 正式 |
| 待处理反馈 | 状态为待处理或处理中的反馈数 | 正式 |
| AI 陪练使用人数 | 固定 mock 占位值 | 占位 |
| 写译提交量 | 固定 mock 占位值 | 占位 |
| 模考完成人数 | 已发布试卷聚合统计中的完成人数 | 正式 Mock |

## 用户增长与活跃

- 新增用户趋势：按 `createdAt` 聚合。
- 活跃用户趋势：按 `lastActiveAt` 聚合。
- 考试目标分布：按用户考试目标聚合。
- Onboarding 分布：按用户 Onboarding 状态聚合。
- 诊断完成率：诊断已完成用户数 / 有诊断状态用户数。
- 今日任务完成率：今日任务已完成用户数 / 有今日任务状态用户数。

## 学习路径

- 诊断开始：有诊断记录或诊断状态不是未开始的用户数。
- 诊断完成：诊断状态为已完成的用户数。
- 命中学习路径：存在学习路径匹配摘要的用户数。
- 生成今日任务：今日任务状态不是未生成的用户数。
- 完成今日任务：今日任务状态为已完成的用户数。
- 平均任务分钟：学习记录分钟数总和 / 学习记录条数。
- 高优先级规则：学习路径配置中优先级小于等于 30 的数量。

## 题库与内容

- 题目总量：当前筛选范围内题目数。
- 可发布题目：状态为已通过、待发布或已发布的题目数。
- 待审核题目：状态为待审核的题目数。
- 审核通过率：题库审核任务中已通过、待发布、已发布、已下架、已回滚任务数 / 非草稿题库审核任务数。
- 题型分布：按客观题题型聚合。
- 状态分布：按审核发布状态聚合。
- 被题组引用题目：被题组引用关系命中的题目数。

## 审核发布

- 待审核：状态为 `pending_review` 的任务数。
- 已通过：当前区间内状态为 `approved` 的任务数。
- 已驳回：当前区间内状态为 `rejected` 的任务数。
- 待发布：状态为 `pending_publish` 的任务数。
- 已发布：当前区间内状态为 `published` 的任务数。
- 已下架：当前区间内状态为 `offline` 的任务数。
- 已回滚：当前区间内状态为 `rolled_back` 的任务数。
- 平均审核时长：已通过或已驳回任务的 `updatedAt - submittedAt` 平均小时数。
- 发布失败、回滚失败：审计日志中对应动作且结果为 failed 的数量。

## 客服反馈

- 反馈总量：用户反馈记录总数。
- 待处理：状态为 `pending` 的反馈数。
- 处理中：状态为 `processing` 的反馈数。
- 已解决：状态为 `resolved` 的反馈数。
- 无需处理：状态为 `no_action` 的反馈数。
- 已关闭：状态为 `closed` 的反馈数。
- 平均处理时长：已解决、无需处理、已关闭反馈的 `updatedAt - createdAt` 平均小时数。
- 反馈类型分布：按反馈类型聚合。

## 模考管理

- 已发布试卷数：状态为 `published` 的试卷数量。
- 开始人数、完成人数：按试卷和时间范围返回聚合 Mock。
- 完成率：完成人数 / 开始人数，空分母显示 0。
- 平均分、平均耗时：仅返回聚合值。
- 分区平均得分：按试卷分区返回平均分、满分、得分率和平均耗时。
- 数据源标记为 `formal=true`，不返回用户 ID、逐题答案或写译原文。

## 占位指标

AI 陪练和写译批改仍为 `formal=false` 占位指标，后续对应业务模块落地后替换为共享 Store 的正式 Mock 聚合数据。
