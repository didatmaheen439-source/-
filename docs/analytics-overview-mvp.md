# 运营数据总览 MVP

日期：2026-07-08

## 页面范围

- 页面入口：`/analytics/overview`
- 页面结构：`PageContainer + 筛选区 + 核心指标卡 + 分区图表 + 数据来源说明 + 导出预览`
- 本阶段只做运营数据总览，不新增独立二级数据分析页，不接真实数据仓库。

## 已实现能力

- 用户增长与活跃概览：新增用户、活跃用户、目标考试分布、Onboarding 分布、诊断完成率、今日任务完成率。
- 学习路径命中与任务完成漏斗：诊断开始、诊断完成、命中学习路径、生成今日任务、完成今日任务。
- 题库内容状态与审核通过率：题目总量、可发布题目、待审核题目、审核通过率、题型分布、状态分布。
- 审核发布统计：待审核、已通过、已驳回、待发布、已发布、已下架、已回滚、平均审核时长、发布失败、回滚失败。
- 客服反馈概览：反馈总量、待处理、处理中、已解决、无需处理、关闭、平均处理时长和反馈类型分布。
- AI 陪练、写译、模考：先以明确标注的占位指标展示，不混入正式聚合口径。
- 数据质量提示：空分母、时间范围异常、部分分区失败、占位指标均在页面上显式提示。
- Mock 导出预览：有导出权限角色可打开预览弹窗，展示可导出字段与过滤条件，不生成真实文件。

## 筛选条件

- 时间范围：默认最近 30 天。
- 考试类型：全部、CET-4、CET-6、考研英语、雅思、托福。
- 统计粒度：日、周、月。
- 模块范围：全部、用户、学习路径、题库内容、审核发布、客服反馈、AI 陪练、写译批改、模考。

筛选参数会同步到 URL query，页面刷新后仍按当前条件加载。

## Mock API

- `GET /api/analytics/overview`
- `GET /api/analytics/overview/export`

支持参数：

- `startDate`
- `endDate`
- `examType`
- `granularity`
- `module`
- `simulateEmpty`
- `simulateFailure`
- `simulateSectionError`

## 权限规则

- `super_admin`：可查看全部分区，可使用导出预览。
- `data_analyst`：可查看全部分区，可使用导出预览。
- `customer_support`：只看用户与客服反馈分区，不显示导出按钮。
- `content_operator`：只看题库内容与审核发布分区，不显示导出按钮。
- `teaching_reviewer`：可看用户、学习路径、题库内容、审核发布、写译占位分区。
- `ai_operator`：可看用户、审核发布、AI 陪练占位、写译占位分区，不显示导出按钮。
- `read_only_auditor`：只看审核发布与审计摘要分区，不显示业务写操作。
- 无运营数据权限角色访问 mock API 返回 403，并写入审计日志。

## 部分成功与错误态

- 整体接口异常：页面展示 `Result 500`。
- 单个分区异常：接口仍返回 200，页面顶部展示部分成功告警，其他分区继续渲染。
- 空数据：页面不显示 NaN 或 Infinity，相关指标展示为 0 或 `-`，并提示数据质量问题。
- 导出无权限：接口返回 403，前端不展示导出按钮。

## 暂未实现能力

- 不接真实 BI、数据仓库或后端聚合服务。
- 不生成真实 Excel/CSV 文件。
- 不做自定义报表、指标拖拽或复杂多维钻取。
- 不开发 AI、写译、模考的完整业务明细页。
- 不接真实用户、真实 AI 或真实学习数据。
