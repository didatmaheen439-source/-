# 运营数据分区 Tab MVP

## 范围

- 可见入口仍为 `/analytics/overview`，不新增侧栏二级菜单。
- 页面内提供 8 个分区 Tab：用户、路径、内容、错因、写译、模考、AI、留存。
- 旧隐藏语义路由继续复用同一页面，新增 `/analytics/retention` 隐藏入口。
- 本阶段继续使用 Mock 聚合，不接真实后端，不写入用户敏感原文。

## 核心流程

1. 数据分析或业务运营进入数据总览。
2. 按日期、考试类型和粒度筛选。
3. 切换分区 Tab 查看对应指标、趋势或分布。
4. 在下钻对象表定位异常对象或可优化队列。
5. 点击查看进入对象详情，或点击发起修正。
6. Mock API 记录修正意图审计日志并返回目标路由。
7. 页面跳转到对象归属模块，由对象模块继续承担编辑、审核、发布或关闭流程。

## 分区对象映射

| 分区 | 数据源 | 下钻对象 | 修正目标 |
| --- | --- | --- | --- |
| 用户 | 用户注册、活跃、学习记录 | 用户 | 用户详情 |
| 路径 | Onboarding、诊断规则、今日任务模板、进阶策略 | 路径匹配 | 学习路径配置 |
| 内容 | 题目、题组、每日一句、外刊、审核任务 | 内容对象 | 内容编辑页 |
| 错因 | 错因标签、题目标签引用 | 错因标签 | 错因标签维护页 |
| 写译 | 写译题目、评分模板、反馈模板、二改策略 | 写译题目、二改策略 | 写译题目或策略页 |
| 模考 | 模考试卷、试卷统计 | 模考试卷 | 试卷编辑页 |
| AI | AI 策略、异常回复 | 异常项、策略 | AI 异常或策略页 |
| 留存 | 用户注册、活跃、学习记录 | 未活跃用户 | 用户详情 |

## 非目标

- 不新增真实导出文件。
- 不在运营数据页直接修改业务对象。
- 不新增侧栏入口。
- 不引入真实 AI、真实埋点或真实后端聚合服务。
