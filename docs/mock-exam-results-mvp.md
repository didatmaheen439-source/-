# 模考结果 MVP

日期：2026-07-13

## 页面范围

- 列表：`/mock-exam/results`
- 关联修正：`/mock-exam/papers/:id/edit`
- 页面目标：从 Mock 聚合结果定位试卷、题目和时间配置问题，并回到试卷草稿完成修正、预校验、审核发布。

## 核心流程

1. 教研或数据角色筛选考试类型、状态、风险类型和时间范围。
2. 页面展示开始人数、完成人数、完成率、均分、平均耗时和风险试卷数。
3. 打开结果详情，查看分区表现、题目风险、时间配置风险和定位建议。
4. 对草稿或已驳回试卷直接进入编辑；对已发布、已下架或已回滚试卷复制为修正草稿。
5. 在试卷编辑页修正题目、分值、分区或时长后，复用既有预校验、审核发布和版本链。

## 风险口径

- 完成率低：完成率低于 60%。
- 均分偏低：全卷得分率低于 60%。
- 分区异常：分区得分率低于 55%，或明显低于全卷均值。
- 题目异常：题目得分率低于 45%，或跳过率高于 30%。
- 时间压力：全卷或分区平均耗时达到配置时长的 95% 以上。
- 校验阻断：试卷最近预校验结果为 `error`。

## Mock API

- `GET /api/mock-exam/results`
- `GET /api/mock-exam/results/:paperId`
- `POST /api/mock-exam/results/:paperId/create-fix-draft`

结果接口只返回聚合数据，不返回用户 ID、逐题答案、作文原文、翻译原文或用户级明细。

## 权限

- `super_admin`：查看结果、创建修正草稿和进入试卷编辑。
- `teaching_reviewer`：查看结果、创建修正草稿和进入试卷编辑。
- `data_analyst`、`read_only_auditor`：只读查看聚合结果。
- `content_operator`、`ai_operator`、`customer_support`：不进入模考管理，页面和 API 直访按既有 `mockExam` 权限返回 403。

## 当前限制

- 本期只使用内存 Mock 数据，不接真实学生端、真实交卷、真实阅卷或真实后端。
- 题目风险和时间风险由稳定 Mock 规则派生，用于验证后台闭环，不代表真实学习效果。
- 修正必须回到试卷草稿和统一审核发布链路，结果页不直接修改线上试卷。
