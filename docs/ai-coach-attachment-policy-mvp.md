# AI 附件策略 MVP

## 入口与边界

- 入口：`/ai-coach/prompts?configType=attachment_policy`
- 附件策略作为“策略配置”页内 Tab，不新增侧栏入口。
- 本阶段只处理 Mock 附件元数据，不上传真实文件，不调用 OCR、ASR 或真实 AI。

## 核心流程

`配置附件类型、格式、大小、识别方式和失败提示 -> 预校验 -> 统一审核发布 -> 已发布版本触发 Mock 会话 -> 会话抽检 -> 失败样例进入异常回复 -> 修复策略与复检`

## 规则

- 附件类型：图片、文档、音频。
- 格式白名单：`jpg/jpeg/png/webp`、`pdf/docx/txt`、`mp3/m4a/wav`。
- 识别方式固定映射为图片 OCR、文档文本提取、音频 ASR。
- 大小上限必须在 `0 < size <= 100 MB` 内。
- 不支持类型、超过大小、识别失败三类提示均为必填。
- 同一业务场景和考试类型不允许与其他已发布附件策略重叠。

## Mock 分流

- `success`：生成待抽检会话，不生成异常项。
- `unsupported_type` / `size_exceeded` / `recognition_failed`：同时生成抽检会话和待处理异常项。
- 失败样例在抽检中判定为正常时，关联异常项按误报关闭；判定为异常时复用原异常项。
- 会话、异常项和修复草稿固化同一附件策略版本快照。

## 真实后端要求

真实接入必须在服务端重新实现权限、乐观锁、幂等、生效范围唯一约束、跨队列事务和审计；禁止将附件原文或识别全文写入审计日志。
