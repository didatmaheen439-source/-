# 外刊内容运营实施与验证记录

## 实施范围

- 外刊列表、新建/编辑、详情、素材预览、效果、版本和操作记录。
- 文章版本快照、审核发布同步、线上版本指针、下架与回滚。
- Mock 用户阅读、收藏、取消收藏和完成事件，以及效果聚合与风险提示。
- 内容运营菜单、审核发布、运营数据和工作台联动。

## 验证记录

- `npm run test -- articleStore routes`：通过，外刊领域与路由测试覆盖校验、快照、版本复制、事件幂等、风险和回滚。
- `npm run test`：通过，16 个测试文件、85 条测试。
- `npm run lint`：通过，Biome 检查 336 个文件无问题，`tsc --noEmit` 通过。
- `npx antd lint ./src`：通过，扫描 301 个文件无问题。
- API smoke：通过同文章 `V1.2` 创建审核快照、审核通过、安排发布、发布、重复事件幂等、下架和回滚；下架后 Mock 目录匹配数为 0，回滚后恢复 `V1.1`。
- 浏览器：教研审核可查看列表、详情、效果和审核任务；内容运营可进入草稿编辑页并查看素材预览；1024×768 下 `bodyScrollWidth === innerWidth`、主内容无横向溢出，素材图片加载成功，最终页面 console 0 error。
- `npm run build`：第一次最终复验因运行中的 Utoo dev 持有 `.turbopack/lock` 被阻断；停止开发服务后重新执行通过，生成 `dist/`，共 64 个资源文件。

## 已知边界

- 当前为 Mock MVP，不接真实移动端、后端、对象存储和定时发布。
- 素材预览使用公开图片 URL，仅用于内部原型；真实接入需替换为受控对象存储和授权信息。
